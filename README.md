# MedPortal Unified

MedPortal is a modern, responsive Healthcare Management System built with React and Redux. It provides a unified workspace for Doctors, Nurses, Patients, and Administrators to manage clinical workflows efficiently.

## Key Features
- **Role-Based Dashboards**: Personalized views for Doctors, Nurses, and Patients.
- **Appointment Management**: Real-time tracking of upcoming visits.
- **Performance Optimized**: Built with memoization and efficient state management.
- **Responsive Design**: Premium UI tailored for both desktop and mobile use.

## Tech Stack
- **Frontend**: React, Redux Toolkit, Redux Saga
- **UI Components**: Ant Design, Styled Components
- **API Client**: Axios with global interceptors

## Getting Started
1. Install dependencies: `npm install`
2. Start development server: `npm start`
3. Build for production: `npm run build`
